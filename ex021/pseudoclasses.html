/* PSEUDO-CLASSES As pseudo-classes servem para aplicar um estilo a um elemento quando ele está em um determinado estado ou condição. A sintaxe é: seletor:pseudo-classe { propriedade: valor; } Exemplos: div:hover { - É ativada quando o ponteiro do mouse passa sobre a div. - Muito utilizada para criar efeitos de destaque e animações. } a:visited { - Aplica um estilo aos links que o usuário já visitou. } a:link { - Aplica um estilo aos links que ainda não foram visitados. } a:active { - É aplicada no momento em que o elemento está sendo clicado. - O efeito dura apenas enquanto o clique acontece. } input:focus { - É ativada quando um campo de texto recebe o foco, ou seja, quando o usuário clica nele ou navega até ele pelo teclado. } input:checked { - É aplicada quando um checkbox ou botão de opção (radio) está marcado. } li:first-child { - Seleciona apenas o primeiro filho de um elemento. - Exemplo: o primeiro item de uma lista. } li:last-child { - Seleciona apenas o último filho de um elemento. } li:nth-child(numero) { - Seleciona um filho específico de acordo com sua posição. - Exemplo: li:nth-child(2) seleciona o segundo item. li:nth-child(odd) seleciona os itens ímpares. li:nth-child(even) seleciona os itens pares. Resumo: - :hover -> mouse sobre o elemento. - :visited -> link já visitado. - :link -> link ainda não visitado. - :active -> elemento sendo clicado. - :focus -> elemento com foco. - :checked -> checkbox ou radio marcado. - :first-child -> primeiro filho. - :last-child -> último filho. - :nth-child() -> filho em uma posição específica. */
